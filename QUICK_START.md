# Quick Start — Using This Infrastructure Template

**Purpose:** Get started with this documentation infrastructure in 5 minutes.

---

## Step 1: Copy to Your Project (1 minute)

```bash
# Copy this template to your new project
cp -r ~/Github/blank ~/Github/your-new-project
cd ~/Github/your-new-project
```

---

## Step 2: Update Project Identity (2 minutes)

Edit `docs/01-orientation/PROJECT_IDENTITY.md`:

```markdown
## Project name and slug

| Field | Value |
|-------|--------|
| **Project name** | YourProject |
| **Project slug** | yourproject |

## Repository role

| Field | Value |
|-------|--------|
| **Repository role** | client | service | worker |
```

---

## Step 3: Read the Guides (2 minutes)

1. Read: `AI.md` (AI behavior rules)
2. Read: `docs/README.md` (navigation spine)
3. Read: `docs/01-orientation/GETTING_STARTED.md` (how to use)

---

## Step 4: Start Building

**Fill these layers with YOUR project data:**

1. **Layer 2 (Canon):** `docs/02-canon/`
   - Create: GUIDELINES.md, PROJECT_SCOPE.md

2. **Layer 3 (Architecture):** `docs/03-architecture/`
   - Create: SYSTEM_MAP.md, database docs

3. **Layer 4 (Behavior):** `docs/04-behavior/`
   - Create: AUTHENTICATION_FLOWS.md, API_MATRIX.md

4. **Layer 8 (Status):** `docs/08-status/`
   - Create your first feature request (Project item with `coordination:feature-request`)
   - Update CURRENT_STATUS.md
