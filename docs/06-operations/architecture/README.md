# Project-Specific Architecture SOPs

**Purpose:** Architecture SOPs that are project-specific (e.g. `SOURCEAPP_FRONTEND_BACKEND_ARCHITECTURE_SOP.md`, `CHEQPASS_*.md`). **Not infrastructure** — do not sync to origin_project template.

**When to add:** When a project has architecture decisions, deployment patterns, or tech-stack guidance that applies only to that project.

**Infrastructure equivalent:** For reusable architecture patterns, see `docs/07-guides/INFRASTRUCTURE_*.md`.
