# Decision Log

**Purpose:** Record major product/technical decisions with rationale and date so "why and when" stays discoverable without rereading feature requests or chat logs.

**How to use**
- Add one row per decision; keep entries concise (1–3 sentences rationale).
- Link to the initiating feature request (Project item or legacy doc) and any impacted docs/PRs.
- Update when decisions are superseded; do not delete old rows—add a "Superseded By" pointer.
