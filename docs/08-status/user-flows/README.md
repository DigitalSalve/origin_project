# User Flow Reports and Flow Documents

**Purpose:** (1) Optional dated reports produced when the [User Flow Identification SOP](../../06-operations/examination/USER_FLOW_IDENTIFICATION_SOP.md) is run as an explicit audit. (2) One document per identified flow and per branching section.

**SOP:** `docs/06-operations/examination/USER_FLOW_IDENTIFICATION_SOP.md`

**Authoritative doc:** `docs/04-behavior/INTENDED_USER_FLOWS.md` — created/updated per User Flow Identification SOP. This folder holds optional per-flow and per-branching docs, and optional time-bound audit reports.

---

## Flow and branching documents

**Fill per project.** Create one document per flow and per branching section identified for your project. Link them here and in `docs/04-behavior/INTENDED_USER_FLOWS.md`.

---

## Optional dated reports

**Report naming:** `{YYYY-MM-DD}_USER_FLOW_MAP_REPORT.md`

**When to add a report:** When you run the User Flow Identification process as a formal pass. The primary deliverable is always `docs/04-behavior/INTENDED_USER_FLOWS.md`; this folder holds optional per-flow docs and time-bound audit reports.

**Logging:** Create Project item with `coordination:report` for one-off reports; SOP-owned reports go in this folder and are linked from docs/README Layer 8.
