# Screen Examination Reports

**Purpose:** Outputs from screen examinations performed per the Screen Examination SOP.

**SOP:** `docs/06-operations/examination/SCREEN_EXAMINATION_SOP.md`

**Report naming:** `{YYYY-MM-DD}_SCREEN_EXAMINATION_REPORT.md`

**Contents:** Each report is a systematic examination of screens identifying stubbed content, mock data, API integration status, and broken functionality.

Reports here are used for migration planning, gap analysis, and implementation verification.
