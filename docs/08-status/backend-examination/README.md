# Backend Examination Reports

**Purpose:** Outputs from backend examinations performed per the Backend Examination SOP.

**SOP:** `docs/06-operations/examination/BACKEND_EXAMINATION_SOP.md`

**Report naming:** `{YYYY-MM-DD}_BACKEND_EXAMINATION_REPORT.md`

**Contents:** Each report is a structured outline of the backend **as-is**, classifying components and processes as **Working**, **Not Working**, or **Needing to be Implemented**.

Reports here are used for migration planning, gap analysis, and implementation verification.
