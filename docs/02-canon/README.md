# Layer 2: Canon and Mandates

**Purpose:** System truth, invariants, compliance, audit rules. **Fill per project.**

**When to read:** Before making any changes that touch canon, compliance, or mandates.

**These are mandates, not suggestions.** When applying this infrastructure to a project, add project-specific canon here.

**Typical files:**
- `GUIDELINES.md` — AI behavior rules and documentation expectations
- `PROJECT_SCOPE.md` — Product boundaries; in-scope vs out-of-scope
- Add others per project: `SYSTEM_CANON.md`, `AUDIT_SCOPE.md`, `CONSENT_AND_AUDIT.md`, etc.

**Link new files** in `docs/README.md` Layer 2 section.
